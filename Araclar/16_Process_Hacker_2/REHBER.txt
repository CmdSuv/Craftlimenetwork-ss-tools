========================================================================
KONUMU:
- Araclar\16_Process_Hacker_2\Process_Hacker_2_Ac.bat (otomatik Yönetici açar)
- Doğrudan exe: Araclar\16_Process_Hacker_2\bin\x64\ProcessHacker.exe

[NE İŞE YARAR?]
Bilgisayar yeniden başlatılmadığı sürece, oyuncu hileyi diskten silmiş
olsa bile Minecraft'ın (javaw.exe) ve kritik Windows servislerinin
RAM'inde yüzen hile adlarını, menü yazılarını, çalıştırılan dosya
yollarını ve bağlanılan web sitelerini gösterir.

[ADIM 1: YÖNETİCİ OLARAK AÇ]
- "Process_Hacker_2_Ac.bat" dosyasına çift tıkla (veya
  ProcessHacker.exe'ye SAĞ TIKLA -> "Yönetici olarak çalıştır" de).
  (Yönetici açmazsan Windows servislerinin RAM'ini okuyamazsın.)

[ADIM 2: MINECRAFT (javaw.exe) RAM TARAMASI]
1. Üstteki "Processes" sekmesinde sağ üst arama kutusuna "javaw" yaz.
2. Çıkan "javaw.exe" üzerine ÇİFT TIKLA (veya Sağ tık -> Properties).
3. "Memory" sekmesine geç -> sağ üstten "Strings..." butonuna tıkla.
4. Açılan pencerede:
   - Minimum length: 4
   - "Image" ve "Mapped" kutucuklarını İŞARETLE -> OK.
5. Sonuç penceresinde sol alttaki "Filter" butonuna tıkla ->
   "Contains (case-insensitive)" seç ve şu kelimeleri tek tek ara:
   - Reach
   - Velocity
   - AutoClicker
   - AimAssist
   - Vape
   - Slinky
   - Drip
   - Doomsday
   - .dll

[ADIM 3: SİLİNMİŞ HİLELERİ YAKALAYAN 3 KRİTİK WİNDOWS SERVİSİ]
Üstten "Services" sekmesine geç -> sağ üstten servis adını ara ->
servise SAĞ TIKLA -> "Go to process" de (seni ilgili svchost.exe'ye
götürür) -> o svchost.exe'ye ÇİFT TIKLA -> Memory -> Strings (4, Image+Mapped):

1) DiagTrack (Connected User Experiences and Telemetry):
   - Filter: .exe
   - Neyi yakalar? Bu oturumda çalıştırılıp sonradan SİLİNMİŞ .exe yollarını.

2) PcaSvc (Program Compatibility Assistant Service):
   - Filter: .exe
   - Neyi yakalar? Son çalıştırılan programların tam yolunu (Desktop,
     Downloads, Temp içinden açılan şüpheli .exe'lere dikkat et).

3) Dnscache (DNS Client):
   - Filter: http  (ardından .com  |  .gg  |  .cc  |  .xyz)
   - Neyi yakalar? Hilenin lisans doğrulamak veya indirmek için bağlandığı
     domain ve web adreslerini.

[NE ÇIKARSA KESİN HİLE / MANİPÜLASYONDUR?]
- javaw.exe içinde hile modülü adı veya Temp/Desktop/AppData'dan yüklü
  imzasız bir .dll yolu -> %100 AKTİF HİLE.
- DiagTrack / PcaSvc içinde Downloads/Desktop/Temp'ten çalışmış şüpheli
  .exe yolu var ama dosya artık klasörde yoksa -> %100 AÇIP SİLMİŞ.
- DiagTrack, PcaSvc veya SysMain servisleri "Stopped" (Durdurulmuş)
  görünüyorsa -> Oyuncu iz bırakmamak için servis kapatmış olabilir!
